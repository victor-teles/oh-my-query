## Adaptations (reported, not silent)

- **Guard.** A single-pass lexer replaces the regex `normalizeSqlForAnalysis`, which could hide code from MySQL. Examples: `'a\''` backslash escapes, `/*! … */` executable comments, `--1` that MySQL does not read as a comment, and `'--'` inside a string. A statement must pass both a standard lexer and a MySQL-style lexer. Also rejected: `commit`, `rollback`, `pragma`, `pg_cancel_backend`, and unterminated strings or comments. `classifyStandardSql` runs on the lexed code, so quoted identifiers like `"update"` are allowed. Accepted cost: Postgres `$$…$$` strings are rejected because the MySQL lexer reads them as code.
- **DuckDB** supports `BEGIN TRANSACTION READ ONLY`, so it gets real enforcement on the same connection, not the guard-only fallback.
- **MSSQL** has no read-only transactions. One batch (`BEGIN TRANSACTION; <sql>; IF @@TRANCOUNT > 0 ROLLBACK`) keeps everything on one pooled connection. If an error aborts the batch, the transaction stays open until the pool resets the connection on reuse (`sp_reset_connection` rolls it back).
- **Structured output (STOP condition 2).** OpenAI strict mode, the AI SDK default, rejects optional fields and `z.record`. The model therefore fills a strict-compatible draft (nullable fields, `formats` as an array). The draft is converted, and then validated against the unchanged `CardSpec` and the result columns. `CardSpec` was not loosened. Untested against live providers.
- **AI error codes.** The contract has no generic AI code. `model_not_found` maps to `AI_AUTH` (fix it in settings). `provider_error`, `context_length` and `unknown` map to `AI_NETWORK` (retry). The message carries the specific explanation.
- **Pre-filter.** Uses token and stem matching on table and column names instead of the renderer's subsequence fuzzy matcher, which matches almost any long name for short tokens. Tables with no match are ranked by row estimate. FK neighbors in both directions are added up to 80 tables. The formatter's old 50-table cap was removed, so the filter owns size policy.
- **Moved modules.** Plan 003 had already moved `ai-errors`/`ai-provider` into `src/bun`. They now live in `packages/agent`, with `ai-provider` renamed `ai-model`. The model test call is `probeModel`. The Redis branch and the chat-style `buildSystemPrompt` of the old schema formatter were dropped, because asks reject Redis.
- **OpenRouter and local models** now use `.chat()` (Chat Completions). The default `createOpenAI()(id)` targets the Responses API, which most OpenAI-compatible servers lack.
- **`@oh-my-query/rpc` index.** The new modules use named re-exports because `export *` with zod pushed the barrel over oxlint's 100-module budget. All contract types and schemas are still exported from the index.
- **Pre-existing bug fixed.** `drivers-sqlite` aliased `"notnull" AS notnull`, which Bun's SQLite 3.54 parses as the NOTNULL operator, so SQLite schema loading failed in the app. The alias is now quoted. Found by the smoke run.
- **Schema cache.** Extracted from `rpc.ts` into `src/bun/schema-cache.ts`, so `getSchema` and ask share one 60s cache.
- **Schema name resolution.** Ask resolves the requested database against `listDatabases()`, preferring requested → connection database → `public`/`main`/`dbo`/`default`, because the stored Postgres "database" is the DB name, not a schema.

- **Slow structured output.** With DeepSeek Flash over OpenRouter, the present call took over 8s and fell back to an inferred card. Watch this in plan 005; if it's common for this provider, the timeout or model choice may need revisiting. The inferred card formats `revenue_cents` as USD currency without dividing by 100. Plan 005's formatter must not show cents as dollars.
- **Fixed after a live benchmark (OpenRouter, 9 models).** The card draft used `z.discriminatedUnion`, which compiles to JSON Schema `oneOf`. OpenAI ("'oneOf' is not permitted") and Anthropic ("Schema type 'oneOf' is not supported") rejected every card request, so cards on those models were always inferred. The draft now uses `z.union` (`anyOf`), with a regression test asserting no `oneOf` reaches the model. A `groupBy` that repeats `x` (seen from Gemini) is now dropped instead of discarding the whole card. Benchmark after the fix (4 questions each, fixture DB, no repairs needed, all 4 ended `done`, median total time): `google/gemini-2.5-flash-lite` 1.8s, $0.19 per 1k asks, 3/4 model cards; `~z-ai/glm-flash-latest` 3.4s, $0.06 per 1k; `mistralai/mistral-small-3.2-24b-instruct` 4.4s, $0.11 per 1k; the current `deepseek/deepseek-v4.1-flash-1017` 5.9s, $0.63 per 1k. Not viable for SQL streaming: `qwen/qwen3.5-flash` leaks its reasoning into the SQL text, and `openai/gpt-5-nano` takes about 14s to the first token.
