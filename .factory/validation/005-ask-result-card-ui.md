## Found and fixed during the desktop pass

- **The global hotkey never worked (plan 002).** Electrobun 2.0.6's `GlobalShortcut` is an `NSEvent` global monitor (confirmed from `libNativeWrapper.dylib`), which macOS feeds only to Accessibility-trusted apps. The owner chose to request Accessibility: `src/bun/accessibility.ts` (tested) with `accessibility-native.ts` (`AXIsProcessTrustedWithOptions` via `bun:ffi`) prompts at launch and re-registers the shortcut once granted.
- **After Esc, the hotkey stopped working.** The app stayed active with no window, and a global monitor never sees keys aimed at its own app. Asking the previous app to activate is ignored under macOS 14+ cooperative activation, so dismissal now calls `-[NSApplication hide:]` on the main thread (`app-hide-native.ts`). Verified with five summon → Esc cycles, hotkey open/close and blur → reopen, with bun logs.
- **The hotkey didn't close an open panel.** Same root cause from the other side. The renderer now closes on its own configured hotkey (`lib/accelerator.ts`, matched on `event.code`).
- **First press after launch was swallowed.** A blur before `rendererReady` lost the dismiss message; bun now hides natively in that case.
- **Cents shown as dollars.** The real model returned `total_revenue_cents` and the card showed $14k for $139.99. Fixed at the source in `packages/agent`: the SQL prompt asks for major units, the card prompt forbids currency on `_cents`, a model's currency format on a `_cents` column is dropped (keeping the rest of its card), and inference no longer maps `*_cents` to currency.
- **Misleading "latest" value on categorical bars.** The legend shows values only along an ordered axis or per pie slice, and the trend glyph is neutral for categories.
- **Still open:** ⌥⇧Space may also type a non-breaking space into the front app, because a monitor cannot swallow keys. A Carbon `RegisterEventHotKey` binding would fix this and remove the Accessibility requirement.

## Adaptations (reported, not silent)

- **SQL streaming box.** While streaming, the SQL fills a fixed 220px box instead of growing line by line, so the panel morphs once and never retargets per chunk. It settles to its content height on `sqlDone`, and the body only animates its position when not streaming.
- **`LauncherSurface` origin fix** (plan-002 code): `originX: 0.5, originY: 0` instead of `transformOrigin: "top center"`.
- **Highlighter.** A small tokenizer (`lib/sql-highlight.ts`) instead of `@lezer/highlight`, which is not a direct dependency. It tolerates partial SQL by construction. `@codemirror/lang-sql` is still in `package.json` but unused by source.
- **Escape.** It stops a running ask and pops back otherwise, which reconciles "Esc Back" with "Cancel: Stop or Esc".
- **⌘C.** Handled once at the ask view (copies the SQL unless text is selected) rather than also inside the SQL block.
- **Footer.** `LauncherFooter` now takes `hints[]`. The ask footer shows Stop while working, and Copy SQL / SQL / Views (⌘1–n) once answered. Root shows "↑ Last answer" when one exists.
- **Browser stub.** Persists the redacted AI settings (never the key) in localStorage, so `dev:web` and e2e reach the ask row. It replays "Revenue by region" (line, 3 series, groupBy), "Weekly signups by plan" (stacked bar, 4 series) and a refusal for prompts with `delete/drop/truncate/update/insert`.
- **`SegmentedControl`** moved from settings to `components/ui/` (second caller: the card view toggle).
- **Bar animation.** Recharts grows bars from the baseline per series (200ms, 12ms stagger between series); a per-bar stagger is not available in Recharts 2.15. Lines draw in 450ms ease-out. Both run on the first render of a live answer only; view toggles, reopened answers and reduced motion skip them.
- **Test harness.** Recharts appends a measuring span to `<body>`, which makes `vitest-browser-react` locate containers by changing text. Tests that render charts and then change state query through `page`, anchored on a test id.
