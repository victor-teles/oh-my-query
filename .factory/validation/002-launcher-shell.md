## Findings for the owner

1. **Keyboard focus after summon (verify first).** Electrobun's `activate()` uses `activateIgnoringOtherApps:`. After a tray summon, `lsappinfo front` still reported the previous app, so on this macOS version the launcher may not receive real keystrokes until clicked. Raycast-style launchers use a non-activating `NSPanel` that can become key without activating the app; Electrobun 2.0.6 exposes no such option. If typing after `⌥⇧Space` goes to the previous app, the fix needs native support (Electrobun option or a small native helper) — it is outside plan 002's allowed scope.
2. **Full-screen Spaces.** `setVisibleOnAllWorkspaces(true)` did not place the panel over another app's full-screen Space during recording. Launchers need `NSWindowCollectionBehaviorFullScreenAuxiliary`; Electrobun exposes only generic collection-behavior plumbing. Verify by pressing the hotkey over a full-screen app.
3. **Global hotkey is not swallowed.** Electrobun registers shortcuts with an `NSEvent` global monitor, so `⌥⇧Space` also reaches the frontmost app (in many text fields `⌥Space` types a non-breaking space). Consider a hotkey whose side effect is harmless, or native `RegisterEventHotKey` support.
4. **Bun-worker deadlock (fixed).** Importing `@oh-my-query/core` directly in `src/bun/index.ts` evaluated polyglot's WASM top-level await before `electrobun/main` and hung the app worker with no output. The config read moved to `src/bun/launcher-config.ts`; a one-line comment guards it.
5. **Router tree was going stale (fixed).** The router plugin wrote `src/routeTree.gen.ts` while the app imported `src/mainview/routeTree.gen.ts`; `generatedRouteTree` now points at the imported file and the orphan is removed from the index.

## Deviations from the plan

- `passthrough: true` makes Electrobun ignore _all_ mouse input, not just transparent pixels, so it is off; the 20 pt shadow margin captures clicks (allowed fallback).
- The window is created visible: a window created with `hidden: true` never loads its webview. The renderer plays the summon animation on mount.
- Placeholder is "Search…" and there is no "Connections" section or `⌘K Actions` hint yet — asking (plan 005), connections (plan 003) and actions don't exist, and the design rules forbid fake controls. Plan 005 should switch the placeholder to "Ask a question or search…".
- The "blur hides unless a native dialog is open" flag is not built: no native dialogs exist yet. Add it with the first file picker (plan 003+).
- Two extra launcher messages (`launcherToggle`, `launcherDismiss`) let the renderer own visual state so a second hotkey press reverses an animation in flight.
- `lib/persistence.ts` and `lib/query-types.ts` were deleted (workspace tab persistence); `RunConfig` moved into `lib/connections.ts`.
